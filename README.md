# Satellite Orbit & Navigation Simulator

A Python-based satellite orbit simulation and visualization project.

## Overview

This project simulates a satellite moving around Earth in a circular orbit. It calculates orbital parameters and visualizes satellite motion using Python and Matplotlib.

## Features

- Circular satellite orbit simulation
- Orbital speed and orbital period calculation
- Satellite position calculation
- 2D orbit visualization
- Animated satellite trajectory
- Live telemetry display
- Velocity and acceleration vector visualization

## Technologies Used

- Python 3.12
- Matplotlib
- PyCharm
- Git and GitHub

## Installation

1. Install Python 3.12.
2. Install Matplotlib:

   ```bash
   pip install matplotlib
   ```

## How to Run

Run the following scripts individually from PyCharm:

- `main.py` — Basic orbit simulation
- `orbital_speed.py` — Orbital speed and period calculation
- `satellite_position.py` — Satellite position calculation
- `position_visualization.py` — Satellite position visualization
- `position_animation.py` — Animated orbit
- `telemetry_display.py` — Live telemetry visualization
